# MRTG + Network Map (s6) Implementation Plan

> **For Hermes:** Use TDD per sub-slice; no orchestration overhead unless multi-domain.

**Goal:** Build SNMP + ping graph engine, client assignment, and admin/NOC network map for INTERCLOUD portal.

**Architecture:** Extend existing `monitoring.py` with async SNMP poller (pysnmp-lextudio or snmp-get CLI), MongoDB time-series collections with downsampling tiers, client-graph assignment via `client_id` field, and a React network map using react-flow or a lightweight SVG canvas. RBAC mirroring existing patterns: admin-only mutations, admin/support read, client read own assigned graphs.

**Tech Stack:** FastAPI + Motor/MongoDB + React + pysnmp-lextudio (pure Python, no system deps) + react-flow (optional, for map).

### Task 1: Add monitoring_graphs collection + model

**Files:**
- Create: `backend/portal/monitoring_graphs.py`
- Modify: `backend/server.py` (add index)

Graph schema:
```python
{
    "_id": ObjectId,
    "name": str,           # "Core Router - eth1 Traffic"
    "target": str,         # "10.0.0.1" (device IP)
    "type": str,           # "snmp_traffic" | "snmp_uptime" | "ping" | "snmp_cpu"
    "snmp_oid": str,       # "1.3.6.1.2.1.2.2.1.10.1" (ifInOctets eth1)
    "snmp_community": str, # "public" (encrypted at rest)
    "interval_seconds": int, # 60 (min 30, max 3600)
    "enabled": bool,
    "client_id": str | None,  # None = internal only, ObjectId = assigned to client
    "unit": str,           # "bps" | "percent" | "ms" | "count"
    "display_name": str,   # optional label override
    "created_by": str,     # admin user id
    "created_at": datetime,
    "updated_at": datetime,
}
```

Indexes in `server.py`:
```python
await db.monitoring_graphs.create_index([("enabled", 1), ("interval_seconds", 1)])
await db.monitoring_graphs.create_index([("client_id", 1)])
await db.monitoring_graphs.create_index([("type", 1)])
```

## Risks & Tradeoffs

1. **pysnmp-lextudio vs snmpget CLI**: pysnmp is pure Python, no system dep, but slower. CLI is faster but needs `snmpget` installed. Start with pysnmp, swap to CLI if perf issues.
2. **react-flow bundle size**: ~200KB gzipped. If too heavy, custom SVG approach is ~20KB.
3. **SNMP community encryption**: Fernet symmetric key, stored in env var. Same pattern as existing `SECRET_KEY`.
4. **Downsampling race**: Single scheduler lease prevents concurrent downsampling. Raw samples may accumulate if downsampling falls behind — accept eventual consistency.
5. **Client data isolation**: Client graph endpoints MUST filter by `client_id`. This is the primary security boundary.
